## 작업 접근 템플릿

- 1단계: 이 작업이 "언제" 실행되는지 찾기
process_exit이 호출 될 때
- 2단계: 이 작업이 "무엇을" 입력으로 받는지 찾기
page를 입력으로 받는다.
- 3단계: 이 작업이 끝나면 "어떤 상태"가 되어야 하는지 정하기
spt가 텅텅 비어있다.
- 4단계: 중간에 실패하면 "무엇이 남으면 안 되는지" 적기
메모리가 할당되어 있다.

### 1. 이 작업 한 줄 정의

spt를 청소하는 작업이다.

### 2. 호출 흐름

thread_exit > process_exit > process_cleanup > supplemental_page_table_kill & pml4_destroy (pml4);

### 3. 내가 건드릴 함수

- supplemental_page_table_kill
- destroy
- vm_dealloc_page

``` c
struct page {
```

```c
void
supplemental_page_table_kill (struct supplemental_page_table *spt UNUSED) {
- spt 테이블을 순회하며
  - frame->page = NULL;
	page->frame = NULL;

	lock_acquire(&frame_table_lock);
	list_remove(&frame->elem);
	lock_release(&frame_table_lock);

	palloc_free_page(frame->kva);

	free(frame);
  - vm_dealloc_page 호출
- hash_destroy 호출
}
```
